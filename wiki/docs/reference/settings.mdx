# All settings

Every setting, as the config screen groups them. Change one with
`/mobstacker set <setting> <value>` or in the [config screen]($reference/config_screen), and see one
with `/mobstacker get <setting>`. `/mobstacker reset <setting>` (or the value `default`) puts it
back, and wherever a whole number is asked for, `max` means as high as it goes.

**Per region**: whether a [region can set its own value]($regions/region_settings) with
`/mobstacker region set <region> <setting> <value>`.

> [!NOTE]
> The deny and allow mob lists and the stack ceilings per mob type are not settings of this kind:
> see [Which mobs stack]($stacking/which_mobs_stack) and
> [How stacks form]($stacking/how_stacks_form#how-big-a-stack-may-grow).

## Stacking

| Setting | Default | Values | Per region | Description |
|---|---|---|---|---|
| `stackMode` | `OFF` | `off`, `regions`, `players`, `everywhere` | no | Where stacking is allowed: OFF, REGIONS (only inside ALLOW regions), PLAYERS (only near a player), or EVERYWHERE. |
| `maxStackSize` | `16` | 1 to 2147483647 | yes | The largest a stack is allowed to grow to. A mob type given its own ceiling ignores this. |
| `stackOnSpawn` | `true` | `true`, `false` | yes | Merge a mob into a nearby stack on its first tick, instead of waiting for it to move or for the next scan. Covers spawners, breeding and spawn eggs. |
| `mobListMode` | `BLACKLIST` | `blacklist`, `whitelist` | yes | Which mob list decides: BLACKLIST (everything stacks except the ignored lists) or WHITELIST (nothing stacks except the allowed lists). |
| `stackRadius` | `6.0` | 0.1 to 42000.0 | yes | How far apart (in blocks) mobs can be and still merge into the same stack. |
| `playerStackRadius` | `12.0` | 1.0 to 42000.0 | no | In PLAYERS stack mode, mobs within this many blocks of any player are allowed to stack. |
| `stackScanInterval` | `20` | 0 to 1200 | yes | How often (in ticks) a mob re-checks for a nearby stack to join, so mobs that never move still merge. 0 only merges when a mob crosses a block boundary. |
| `stackEquippedMobs` | `false` | `true`, `false` | yes | Allow mobs that hold or wear items to stack. Off keeps an armed or armored mob out of stacks entirely. |
| `keepMemberEquipment` | `true` | `true`, `false` | yes | Remember what every mob in a stack wears and holds, so its own gear drops when it is killed instead of being lost on the merge. Needs `stackEquippedMobs`. |
| `stackNamedMobs` | `false` | `true`, `false` | yes | Let mobs renamed with a name tag stack with other mobs of the same name. Off protects a named mob from being absorbed, but a stack that is renamed keeps stacking either way. |
| `strictDataComparison` | `true` | `true`, `false` | yes | Mobs merge only if the data other mods saved on them is the same - a level, an affix, a champion's rank - so a merge never throws it away. Vanilla's own data is matched by the mod's own rules. /mobstacker inspect names the key that differs. |
| `ignoredDataKeys` | empty | text | yes | Keys of other mods' data that strictDataComparison leaves out, comma-separated: Key, or Container.key for one entry inside a compound such as ForgeCaps. For a mod that keeps a timer on every mob, which would otherwise stop its mobs from stacking. Needs `strictDataComparison`. |
| `stackBosses` | `false` | `true`, `false` | yes | Let bosses stack. A boss is a mob with a boss bar of its own, one in the #mobstacker:bosses tag (the ender dragon, the wither, the warden, the elder guardian, and the loader's #c:bosses or #forge:bosses), or one whose base health reaches bossHealthThreshold. |
| `bossHealthThreshold` | `150` | 0 to 1000000 | yes | A mob kind whose base max health is at least this counts as a boss, which catches other mods' bosses that have no boss bar (vanilla: the wither 300, the dragon 200, a ravager 100). 0: only boss bars and the tag count. Does nothing while `stackBosses` is on. |
| `killWholeStackOnDeath` | `false` | `true`, `false` | yes | Killing the top mob kills the entire stack at once (disables damage overflow). Forced on while `stackHealth` is on. |
| `stackHealth` | `false` | `true`, `false` | yes | A stack's health scales with its size. Forces killWholeStackOnDeath on for as long as it is on. |
| `stackAi` | `NORMAL` | `normal`, `physics_only`, `frozen` | yes | What a stack of two or more mobs does with its AI. NORMAL: it thinks like any mob. PHYSICS_ONLY: it attacks nothing, follows nobody and stands still, but still falls, is carried by water, knocked back and kept afloat, so farms keep working (sheep do not eat grass, so their wool does not grow back, and villagers do not work). FROZEN: vanilla NoAI, it does not move at all, not even to fall. A single mob always keeps its AI. |

## Spawning & despawning

Vanilla's spawn caps, each as a setting (global only), with every mob in a stack counted towards
them, and what despawns. See [For server owners]($reference/server_owners#spawning-and-despawning).

| Setting | Default | Values | Per region | Description |
|---|---|---|---|---|
| `countStackMembers` | `true` | `true`, `false` | no | Every mob in a stack counts towards the spawn caps, so a world with stacks has as many mobs as vanilla, in fewer entities. Off: a whole stack counts as one mob, so far more mobs can exist at once (and farms that spawn give more). |
| `monsterMobCap` | `70` | 0 to 128 | no | Spawn cap for the monster category (vanilla 70). |
| `creatureMobCap` | `10` | 0 to 128 | no | Spawn cap for the creature (animal) category (vanilla 10). |
| `ambientMobCap` | `15` | 0 to 128 | no | Spawn cap for the ambient (bat) category (vanilla 15). |
| `axolotlsMobCap` | `5` | 0 to 128 | no | Spawn cap for axolotls (vanilla 5). |
| `undergroundWaterCreatureMobCap` | `5` | 0 to 128 | no | Spawn cap for underground water creatures, i.e. glow squid (vanilla 5). |
| `waterCreatureMobCap` | `5` | 0 to 128 | no | Spawn cap for water creatures: squid, dolphins (vanilla 5). |
| `waterAmbientMobCap` | `20` | 0 to 128 | no | Spawn cap for water ambient mobs: fish (vanilla 20). |
| `despawnPickedUpMobs` | `false` | `true`, `false` | yes | A mob that picks up an item (a zombie taking a sword off the ground) can still despawn, and drops what it picked up when it goes; an enderman carrying a block drops the block. | `persistentStackSize` | `0` | 0 to 2147483647 | yes | A stack of at least this many mobs never despawns on its own, for pens and farms that keep their mobs. 0: a stack despawns like any single mob, as vanilla would despawn the crowd it stands for. |
